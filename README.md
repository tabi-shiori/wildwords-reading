1. **翻倍与减半**：古埃及的加倍算法 → 二进制组合 → 芯片增长 → A4 纸减半后的比例。35 个目标词，241 词。

## 功能

- 阅读：点词、音标、完整常见义项、本文用法、原句、中英对照、遮挡自测。
- 朗读：浏览器英语语音合成，可选择语音和语速。
- 练习：每篇 3 道阅读判断题；篇下复习覆盖该篇所有词；主复习覆盖全部 75 个词。四选一，支持英选汉、汉选英和双向交替。
- 多义词：按词性逐项展开，中文选项完整换行；出题时遮挡释义搭配中的目标英文。
- 记录：掌握标记、收藏、已读和成绩存于当前浏览器，支持 JSON 导入合并与导出。
- iPhone 紧凑布局，保留 Chapter 3 / 4 / 5 / 5B 的入口。

## 重写后的记录
