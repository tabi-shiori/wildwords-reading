# FIELDNOTES · 动物保护词汇阅读

6 篇原创双语短文，覆盖 90 个动物保护主题词汇。

## 功能

- 点词查看音标、中文释义与原句
- 高亮阅读、中文提示、遮挡自测和中文译文
- 单词及全文朗读（使用设备英文语音）
- 已掌握标记、词汇搜索、两种方向的选择题

## 部署

这是无需安装或构建的静态网站。GitHub Pages 使用 main 分支的根目录发布，保留 `.nojekyll`。全部网页资源均使用相对路径。

## 学习进度

阅读偏好和已掌握词汇保存在当前浏览器的 localStorage 中，键名为 `fieldnotes-wildwords-v1`。更换域名、设备或浏览器不会自动同步原有进度。站点本身不上传学习数据。
